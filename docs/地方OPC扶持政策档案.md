# 地方 OPC 扶持政策档案

> **用途：** 为失败案例库提供"政策环境"维度的对照数据，同时作为选题原料。
>
> **收录原则：** 只记录可溯源的公开信息，标注来源与发布日期。官方披露数据必须注明其统计口径与选择性偏差。
>
> **当前收录：** 重庆（1 个城市，5 个层级样本）

---

## 为什么失败档案馆要收政策

一个 OPC 项目的存活，不完全是产品问题。政策补贴、免费工位、订单分发会直接改变成本结构和现金流，从而推迟或改变死亡时间点。

如果不记录政策环境，会出现两个失真：

1. **把政策红利误判为产品能力。** 一个靠免费工位和算力补贴活着的项目，账面看起来是"活着的"，但它验证的是政策而不是市场。
2. **把政策退坡误判为产品失败。** 补贴到期后集中死亡的项目，死因会被归为"商业模式脆弱"，实际是外部条件变化。

所以政策档案在信息模型里不是附属信息，它是**解释存活时长的必要条件**。

### 二、"1+1" 机制拆解

#### 环节一：OPC 资源对接会

**内容：** 政策宣讲、社区推介、金融授信、项目展示、嘉宾分享。

**四大功能区：**

1. OPC 创业项目展示
2. OPC 社区入驻洽谈
3. 金融资源对接
4. 创业导师服务

**关键设计——需求前置匹配：**

这是本次活动与常规创业服务活动最大的差别。主办方在**报名阶段**就开始征集需求：

- 提前摸排创业者在政策、资金、场地、技术、市场五方面的核心痛点
- 据此调整创业导师的辅导方向
- 针对性匹配金融担保机构及人工智能资源机构专家

官方表述是"打破传统'大锅饭'式的交流，把资源精准匹配贯穿到筹备全过程"，目标是让资源对接"可谈、可签、可办"。

#### 环节二：OPC 赋能实训营

**内容：** 组织创业者走进 OPC 社区，开展社区体验、实战指导、案例分享、导师问诊。

**目标：** 帮助创业者"迭代人工智能创业认知体系"。

### 四、数据可信度评估

**这是本档案最重要的一节。**

重庆官方披露的数据全部是**正向指标**：入驻企业数、释放订单额、营收额、满意度、获奖情况。

**完全没有披露的指标：**

- 入驻企业的存活率 / 退出率
- 平均存活时长
- 订单分发的持续性（350 万是累计还是年度？拆分到 30 多家，户均多少？）
- 补贴退坡后的续存情况
- 未入驻 / 退出的企业数量

**这意味着：**

1. 这些数字**不能直接作为"重庆模式有效"的证据**。没有分母，就没有存活率。
2. 123 家企业入驻是存量快照，不是累计孵化数。看不到流失。
3. "企业满意度 90%+"是受访者自评，不是经营结果。

**对失败档案馆的价值恰恰在这里：**

全网都在转述这些正向数字，没有人问分母。如果我们能把"入驻数"和"实际存活数"放在一起，这就是一个别处拿不到的对照。

### 五、可做的选题角度

按写作红线，只陈述事实与对照，不给建议。

| 角度 | 可用的对照事实 | 需要的补充数据 |
|---|---|---|
| **重庆 5 个区同时做 OPC，谁的模式不一样** | 渝中给订单、南岸给算力+内容赛道、两江给零租工位、开州给注册地址+条例 | 各区的入驻数与退出数 |
| **"给订单"和"给工位"是两种完全不同的政策** | 渝中订单分发 350 万 / 30 多家参与；两江 174 个零租工位 / 68 家入驻 | 两类模式下企业的收入结构差异 |
| **官方披露了什么、没披露什么** | 有：入驻数、订单额、营收、满意度。无：存活率、退出数、存活时长 | 无（这本身就是一个观察） |
| **政策定位差异：就业框架 vs 科技框架** | 市级文件把 OPC 放在人力资源服务业下，考核目标是带动就业 | 各区考核指标 |
| **订单分发的真实含金量** | 350 万累计 / 30 多家参与 = 户均约 11 万（累计，非年度） | 订单的持续性、是否可复购 |

### 六、对产品（R2 信号基准）的潜在价值

PRD 里 R2（同赛道同等信号下的后续走向分布）目前数据几乎为零，最大缺口是**可验证的量化口径**。

重庆这批 OPC 有一个别处没有的条件：**官方明确承诺"跟踪帮扶 + 成果回访"**。如果这些回访数据被公开，就是罕见的、带官方背书的存活数据。

但要注意两点：

1. **这是潜在来源，不是现有来源。** 目前没有任何公开的回访数据。
2. **即使公开，也是政策扶持组的样本，不能代表全体 OPC。** 用它做基准时必须标注"政策扶持组"，否则会产生新的偏差。

**可执行的动作：** 持续关注重庆市就业服务管理局及各区人社部门的年度公开信息，一旦出现回访类数据，优先收录。
